BIRTHDAY SURPRISE WEBSITE 💗

Files:
- index.html : page content
- style.css  : design and animations
- script.js  : Yes/No buttons and gift interaction

How to open on your laptop:
1. Extract BirthdaySurpriseWebsite.zip.
2. Open the extracted BirthdaySurpriseWebsite folder in VS Code.
3. Double-click index.html, or right-click it and choose "Open with Live Server" if you have the Live Server extension.
4. Make sure all three files stay in the same folder.

To customize:
- In index.html, change "Happy Birthday, sweetheart!" and the birthday wish.
- Change the question "Oya mata adareida?" if you want.
- No internet is needed for the main design and interactions. The optional Google font needs internet; a fallback font is included.
